# JianNote — 구글 플레이 출시 가이드

## 1. 업로드 파일
- GitHub Releases의 **`JianNote-v1.1.N-playstore.aab`** 를 플레이 콘솔 → 프로덕션(또는 내부 테스트) → 새 버전 만들기에 업로드
- 버전 코드는 GitHub Actions 실행 번호로 자동 증가합니다.
- **Play App Signing(구글 앱 서명) 사용**을 선택하세요. 저장소의 `app/inkshelf.keystore`는 *업로드 키*가 됩니다.
