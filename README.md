# JianNote

갤럭시탭(S7 FE 등) S펜용 손글씨 노트 앱 — Noteshelf 3 / GoodNotes 스타일.

## 주요 기능
- 서재: 노트북 표지, 검색, 즐겨찾기, 복제, 이름/표지 변경
- 일반 노트(A4 세로/가로) + **무한 캔버스**
- 속지 8종(무지·줄·모눈·도트 / 👑 촘촘한 모눈·코넬·오선지·체크리스트), 종이 색 5종
- 펜(볼펜·만년필·붓펜) **S펜 필압 감지** + 필압 감도 조절, 형광펜
- 지우개(부분/획), **S펜 측면 버튼 = 지우개**
- 올가미 선택: 이동·크기조절·삭제·복제·색 변경·다른 레이어로 이동
- 도형 도구(직선·화살표·사각형·원·삼각형) + 펜을 멈추면 도형 자동 보정
- 텍스트, 이미지 삽입
- **레이어**: 추가/삭제/순서/숨김/불투명도/병합
- 실행취소/다시실행, 페이지 추가·복제·이동·삭제·목록
- 손바닥 무시(펜이 화면 근처일 때), 두 손가락 확대/이동, 스와이프 페이지 넘김
- PDF / PNG 내보내기 및 공유

## 요금
모든 기능을 제한 없이 무료로 사용할 수 있습니다 (노트·레이어·속지 무제한, 워터마크 없음).
