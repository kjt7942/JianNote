# JianNote

갤럭시탭(S7 FE 등) S펜용 손글씨 노트 앱 — Noteshelf 3 / GoodNotes 스타일.

## 주요 기능
- 서재: 노트북 표지, 검색, 즐겨찾기, 복제, 이름/표지 변경
- 일반 노트(A4 세로/가로) + **무한 캔버스**
- 속지 8종(무지·줄·모눈·도트 / 👑 촘촘한 모눈·코넬·오선지·체크리스트), 종이 색 5종
- 펜(볼펜·만년필·붓펜) **S펜 필압 감지** + 필압 감도 조절, 형광펜
- 지우개(부분/획), **S펜 측면 버튼 = 지우개**
- 올가미 선택: 이동·크기조절·삭제·복제·색 변경·다른 레이어로 이동
- 도형 도구(직선·화살표·사각형·원·삼각형) + 펜을 멈추면 도형 자동 보정
- 텍스트, 이미지 삽입
- **레이어**: 추가/삭제/순서/숨김/불투명도/병합
- 실행취소/다시실행, 페이지 추가·복제·이동·삭제·목록
- 손바닥 무시(펜이 화면 근처일 때), 두 손가락 확대/이동, 스와이프 페이지 넘김
- PDF / PNG 내보내기 및 공유

### 1.2 추가 기능 (지안이 피드백 반영)
- 펜 종류 추가: 연필 · 마커 · 에어브러시 · 붓/수채, 펜·형광펜 끝 네모나게
- 모든 색상에 투명도 조절, 스포이드(화면에서 색 집기), 펜 호버 시 굵기 원 표시
- 펜·형광펜·지우개 목록(선 미리보기 + 이름 + 굵기), 내 펜 저장
- 낙서해서 지우기, 형광펜만 지우는 지우개
- 도형 보정 후 계속 누른 채 크기·길이·방향 편집, 곡선 보정, 매끄러운 원/획
- 사각형 올가미, 펜만/형광펜만/이미지만/텍스트만 선택, 크기 조절 시 선 두께 유지
- 텍스트·이미지 꾹 눌러 바로 편집, 요소 고정/해제, 올가미 편집 1회 후 이전 도구로 복귀
- 노트 분류(카테고리), 표지 직접 색 · 사용자 이미지 표지, 종이 색 직접 선택
- 이미지를 페이지로 가져오기, 레이어 개수 무제한, 텍스트 배경 팔레트·투명도
- 스크롤·확대 시 페이지 캐시로 부드럽게
