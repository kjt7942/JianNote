# JianNote

갤럭시탭(S7 FE 등) S펜용 손글씨 노트 앱 — Noteshelf 3 / GoodNotes 스타일. 모든 기능 무료·무제한.

> 작업 현황·남은 작업: [PROGRESS.md](PROGRESS.md)

## 기능

**필기**
- S펜 필압 감지(감도 조절), 측면 버튼 = 지우개, 펜이 화면 가까이 있으면 손바닥 무시·굵기 원 표시
- 펜 7종: 볼펜·만년필·붓펜·연필·마커·에어브러시·붓/수채, 형광펜 / 끝 둥글게·네모나게
- 펜·형광펜·지우개 목록(선 미리보기 + 이름 + 굵기), 내 펜 저장
- 모든 색 투명도, 색상 선택기 + 내 팔레트, 스포이드
- 지우개: 부분 / 획 / 형광펜만, 낙서해서 지우기
- 도형 도구 + 펜을 멈추면 도형·곡선 자동 보정, 보정 후 누른 채 크기·길이·방향 편집

**편집**
- 올가미(자유·사각형), 펜만·형광펜만·이미지만·텍스트만·테이프만·메모지만 선택
- 이동·크기 조절(선 두께 유지)·복제·색 변경·레이어 이동·고정/해제, 편집 1회 후 이전 도구로 복귀
- 텍스트·이미지·메모지·테이프 꾹 눌러 바로 편집
- 텍스트: 한글 글꼴 9종, 크기·굵게·기울임·밑줄·취소선·정렬, 형광 배경 + 투명도
- 레이어 무제한(숨기기·순서·투명도·병합), 실행취소/다시실행

**암기 테이프 · 메모지 · 스티커**
- 암기 테이프: 터치하면 비침 ↔ 가림, 테이프 위 쓰기 모드, 아래 내용과 붙이기/떼기, 무늬·색·두께
- 메모지: 텍스트 상자 같은 직사각형, 양식(무지·줄·모눈·체크리스트)·색, 위에 쓴 글씨와 함께 이동
- 스티커: 기본 세트(테이프·메모지·꾸미기), 내 이미지 스티커, 필기를 스티커로 저장

**페이지 · 노트**
- 세로 스크롤 페이지(방향 고정 스크롤) + 오른쪽 페이지 미리보기 패널·북마크, 무한 캔버스
- 페이지 크기: A4(기본)·A5·B5·A3·B4·레터·리갈·정사각형·태블릿 화면·직접 입력(mm), 가로/세로
- 속지 8종 + 사진·PDF로 속지 만들기, 종이 색 직접 선택
- 서재: 분류(카테고리), 검색·정렬·즐겨찾기, 표지 색·사용자 이미지 표지
- PDF·이미지 가져오기(필기), PDF·PNG 내보내기, 노트 백업(.jnote)·복원
- 30초 자동저장, GitHub Releases 자동 업데이트

## 빌드 · 설치
`main`에 푸시하면 GitHub Actions가 APK(직접 설치)·AAB(플레이 스토어용)를 빌드해 **Releases**에 올립니다.
설치된 앱은 새 릴리스를 자동으로 받아 업데이트합니다.
